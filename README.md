# 🏷️ Pak Classified

A simple full-stack web application for buying and selling used products online (like OLX-style platform).

## 🚀 Project Overview

Pak Classified is a platform where users can:
- Post ads for products they want to sell
- Browse products posted by others
- Search and filter items easily
- Contact sellers directly

This project is built for learning and real-world practice of full-stack development.

---

 Tech Stack

- Frontend: HTML, CSS, JavaScript  React 
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT 

---

 Features

- 👤 User Registration & Login
- 📦 Add, Edit, Delete Product Listings
- 🔍 Search Products
- 📱 Responsive UI
- 🔐 Secure Authentication (JWT)
